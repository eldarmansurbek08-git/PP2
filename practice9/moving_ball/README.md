🎮 Pygame Moving Ball Game

This is a simple beginner-friendly game made with Python and Pygame.

📌 Project Description

In this game, you control a red ball on the screen using arrow keys.
Each key press moves the ball by 20 pixels.
The ball cannot move outside the screen boundaries.

🧠 Features
🪟 Game window (600x400)
🔴 Red ball movement
⌨️ Arrow key controls
📏 Step movement (20 pixels per press)
🧱 Boundary protection (no going off-screen)
🎮 Controls
Key	Action
⬅ Left Arrow	Move left
➡ Right Arrow	Move right
⬆ Up Arrow	Move up
⬇ Down Arrow	Move down
