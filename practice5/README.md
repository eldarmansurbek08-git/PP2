# Practice 5 - Python RegEx

## 📌 Objective
This practice is about using Regular Expressions (RegEx) in Python.
We learned how to search, match, split, and replace text patterns.

## 🧠 Topics Covered
- re.match()
- re.search()
- re.findall()
- re.sub()
- Patterns and metacharacters
- Working with strings

## 📝 Tasks
In this practice, I solved the following problems:

1. Match strings with 'a' followed by zero or more 'b'
2. Match strings with 'a' followed by 2-3 'b'
3. Find lowercase words joined with underscore
4. Find uppercase followed by lowercase letters
5. Match 'a' followed by anything and ending with 'b'
6. Replace spaces, commas, and dots with colon
7. Convert snake_case to camelCase
8. Split string at uppercase letters
9. Insert spaces before capital letters
10. Convert camelCase to snake_case
